② 크롤링 구현 예시 (BeautifulSoup 사용)
python
import requests
from bs4 import BeautifulSoup

url = 'https://www.example-b2b.com/products'
headers = {'User-Agent': 'Mozilla/5.0'}
res = requests.get(url, headers=headers)
soup = BeautifulSoup(res.text, 'html.parser')

# 예시: 상품 이름과 가격 추출
products = soup.select('.product-item')
for item in products:
    name = item.select_one('.product-name').text
    price = item.select_one('.price').text
    print(name, price)
③ 수집 데이터 저장 및 가공
Pandas로 처리: DataFrame에 저장 후 누적 저장

SQLite나 Oracle에 저장 가능

python
import pandas as pd

data = {
    '상품명': ['김치', '두부', '계란'],
    '가격': [4500, 1200, 3300],
    '날짜': pd.Timestamp.now()
}
df = pd.DataFrame(data)
df.to_csv('product_data.csv', mode='a', header=False, index=False)
④ 머신러닝 수요 예측 모델 적용 (예: XGBoost)
python
from xgboost import XGBRegressor
from sklearn.model_selection import train_test_split

# 예시용 데이터
df = pd.read_csv('product_data.csv')
X = df[['가격']]  # 예: 입력은 가격
y = df['수요']    # 예: 과거 판매량 (수요)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
model = XGBRegressor()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
