**장마철 침수 위험 예측 시스템** 개발
이 시스템은 **실시간 기상 및 지형 데이터를 활용**하여 지역별 침수 위험도를 예측하고, 
**웹 대시보드와 사용자 알림**을 통해 정보를 제공하는 것을 목표로 합니다. 

 **필요한 데이터 수집 경로**,
 **예측 및 시각화에 적합한 다양한 모델 후보**, 
 **팀원별 역할 분담**,
 **전반적인 시스템 흐름도** 

이 프로젝트는 시민의 안전과 재산 보호에 기여하며, 
**데이터 사이언스 기술 실무 적용**의 좋은 사례가 될 것.



장마철 침수 위험 예측 시스템 프로젝트 브리핑 문서
1. 프로젝트 개요
"장마철 침수 위험 예측 시스템"은 기상 정보와 지형 데이터를 활용하여,
지역별 침수 위험도를 실시간으로 예측하고, 이를 웹 대시보드 및 사용자 경고 알림으로 
제공하는 것을 목표로 합니다. 

이 프로젝트는 "시민의 생명·재산 보호"라는 사회적 문제 해결에 기여하고, 
"지자체 및 공공기관 활용 가능"하며, "데이터 사이언스 실무 적용 포트폴리오 확보"에도 
중요한 역할을 할 것으로 기대됩니다.


2. 핵심 기능
실시간/예측 강우량 분석: 기상청 OpenAPI 등에서 강수량 데이터를 수집하여 분석합니다.
침수 위험 등급화: 분석된 데이터를 기반으로 침수 위험도를 '낮음/보통/높음'으로 분류합니다.
지도 기반 침수 위험 시각화: GeoPandas, Folium, QGIS 등을 활용하여 침수 위험 지역을 
지도 위에 시각적으로 표현합니다.
*사용자 위치 기반 침수 경고 알림 기능: Firebase, 위치 기반 서비스 API(Kakao, Naver 지도 등)를 
통해 사용자에게 침수 경고를 전송합니다.


3. 데이터 수집 경로 및 활용
다양한 공공 데이터를 활용하여 시스템의 정확성을 높입니다.

3-1. 기상 데이터 (강수량 등): "시간당/누적 강수량, 풍속, 습도 등"은 
"기상청 OpenAPI 또는 공공데이터포털"에서 수집합니다.
3-2. 지형 데이터 (고도 등): "지역별 고도, 경사, 하천 분포 등"은 
"국토지리정보원 DEM, 공공데이터포털 DEM"을 활용합니다.
3-3. 침수 이력 데이터: "과거 침수 발생 지역 및 시간"은 
"서울시 침수지도, 행안부/지자체 재해이력"에서 얻습니다.
3-4. 인구/시설 밀집도: "위험도 가중치에 활용"하기 위해 
"통계청, 행정구역 정보"를 참고합니다.


4. 모델 후보 및 기술 스택
다양한 목적에 맞춰 최적의 모델과 기술을 선정할 예정입니다.

시계열 예측 (강우량 예측): LSTM, Facebook Prophet, ARIMA
침수 위험도 분류 (위험 등급화): XGBoost, RandomForest, LightGBM
공간분석/시각화 (침수위험지도): GeoPandas, Folium, QGIS
백엔드: Flask (Python)
웹 대시보드: Plotly, Folium, HTML/CSS, Streamlit or Flask
알림 기능: Firebase, 위치 기반 서비스 API (Kakao, Naver 지도 등)
데이터 처리: Pandas, API, 정규표현식
모델링/평가: Scikit-learn, XGBoost, Prophet
고급 옵션: 위성 이미지 분석(딥러닝)은 팀 여유가 있을 때 고려됩니다.


시계열 예측 (강우량 예측)  
- Facebook Prophet, ARIMA  
- TensorFlow 기반 LSTM (딥러닝 모델은 성능 개선 시 적용)

침수 위험도 분류 (등급화)  
- Scikit-learn, XGBoost, LightGBM

공간 분석 및 지도 시각화  
- Folium, GeoPandas  
- QGIS (웹 통합은 아니며 필요 시 외부 사용)

백엔드  
- Flask (Python 기반 웹 서버)

웹 대시보드  
- Flask + Plotly, Folium, HTML/CSS/JavaScript  
- *Streamlit은 독립형 앱이라 현재 프로젝트에선 보류*

알림 기능  
- 추후 확장 시 Firebase or 이메일 API  
- 위치 기반 경보용 Kakao, Naver 지도 API 활용 가능성 검토

데이터 수집 및 처리  
- Pandas, OpenAPI 활용, 정규표현식 등

데이터베이스  
- Oracle DB 사용 (수집 데이터 저장 및 관리)

개발 도구  
- VS Code, Jupyter Notebook (모델링, 실험용)


5. 시스템 흐름도 (플로우차트)
시스템은 다음과 같은 단계를 거쳐 작동합니다.

데이터 수집: [기상청 API]와 [지형/고도 데이터]를 수집합니다.
데이터 전처리 및 병합: 수집된 데이터를 전처리하고 통합합니다.
예측 모델 실행: 통합된 데이터를 기반으로 예측 모델을 실행합니다.
침수 위험도 등급 분류: 예측 결과를 바탕으로 침수 위험도를 분류합니다.
정보 제공:지도 기반 시각화: 사용자에게 웹 대시보드를 통해 침수 위험 지도를 제공합니다.
사용자 침수 알림 전송: Firebase 및 위치 기반 서비스를 통해 사용자에게 알림을 전송합니다.
