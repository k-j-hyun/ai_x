✅ 1. 데이터 전처리 및 분할

🎯 독립변수(X), 종속변수(y)
- 종속변수(y): is_flood_risk (강수량이 50mm 이상이면 1, 아니면 0으로 설정)
- 독립변수(X): 수치형 변수 중에서 종속변수 및 실제 침수 여부(actual_flood)를 제외한 모든 변수

```python
feature_cols = df.select_dtypes(include=[np.number]).columns.tolist()
feature_cols = [col for col in feature_cols if col not in ['is_flood_risk', 'actual_flood']]
X = df[feature_cols].fillna(df[feature_cols].median())
y = df['is_flood_risk']
```

🔀 학습용/테스트 데이터셋 분할

```python
split_idx = int(len(X) * 0.8)  # 80% 학습, 20% 테스트
X_train, X_test = X.iloc[:split_idx], X.iloc[split_idx:]
y_train, y_test = y.iloc[:split_idx], y.iloc[split_idx:]
```

⚖️ 정규화 (StandardScaler 사용)

```python
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

🔮 Transformer
```python
from tensorflow.keras.layers import Input, MultiHeadAttention, LayerNormalization, Dense, GlobalAveragePooling1D, Dropout
from tensorflow.keras.models import Model

inputs = Input(shape=(14, num_features))
# 🧠 Self-Attention: 각 시점 간 중요도 학습
attention = MultiHeadAttention(num_heads=8, key_dim=64, dropout=0.1)(inputs, inputs)
# 🔁 Residual + 정규화
attention = LayerNormalization(epsilon=1e-6)(inputs + attention)
# FFN: 피드포워드 신경망
ffn = Dense(128, activation='relu')(attention)
ffn = Dropout(0.1)(ffn)
ffn = Dense(num_features)(ffn)
ffn = LayerNormalization(epsilon=1e-6)(attention + ffn)
# Pooling + MLP
pool = GlobalAveragePooling1D()(ffn)
outputs = Dense(64, activation='relu')(pool)
outputs = Dropout(0.3)(outputs)
outputs = Dense(32, activation='relu')(outputs)
outputs = Dropout(0.2)(outputs)
outputs = Dense(1, activation='sigmoid')(outputs)

model = Model(inputs=inputs, outputs=outputs)
model.compile(optimizer=Adam(learning_rate=0.001), loss='binary_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, validation_data=(X_test, y_test), epochs=50, batch_size=32)
```
