### 🔮 Transformer (주석 추가)
```python
from tensorflow.keras.layers import Input, MultiHeadAttention, LayerNormalization, Dense, GlobalAveragePooling1D, Dropout
from tensorflow.keras.models import Model

# 입력: (시퀀스 길이, 특성 수)
inputs = Input(shape=(14, num_features))

# 🔁 Self-Attention 수행 (입력 간 관계 학습)
attention = MultiHeadAttention(num_heads=8, key_dim=64, dropout=0.1)(inputs, inputs)

# ⛓ Add & Norm: 원래 입력(inputs)과 attention을 더한 뒤 정규화
attention = LayerNormalization(epsilon=1e-6)(inputs + attention)

# 🔧 Feed Forward Network (FFN)
ffn = Dense(128, activation='relu')(attention)  # 첫 번째 Dense
ffn = Dropout(0.1)(ffn)                         # 과적합 방지
ffn = Dense(num_features)(ffn)                  # 두 번째 Dense로 차원 맞추기

# ⛓ Add & Norm: attention 출력과 ffn 출력 더함 + 정규화
ffn = LayerNormalization(epsilon=1e-6)(attention + ffn)

# 🔄 전 시퀀스 평균을 취해서 마지막 분류를 위한 벡터 추출
pool = GlobalAveragePooling1D()(ffn)

# 🎯 출력층 (MLP 구조)
outputs = Dense(64, activation='relu')(pool)
outputs = Dropout(0.3)(outputs)
outputs = Dense(32, activation='relu')(outputs)
outputs = Dropout(0.2)(outputs)
outputs = Dense(1, activation='sigmoid')(outputs)  # 이진 분류

# 전체 모델 정의
model = Model(inputs=inputs, outputs=outputs)
model.compile(optimizer=Adam(learning_rate=0.001), loss='binary_crossentropy', metrics=['accuracy'])

# 훈련
model.fit(X_train, y_train, validation_data=(X_test, y_test), epochs=50, batch_size=32)
```

☑️ 요약
- `inputs + attention`: residual connection. 모델이 원래 입력 정보를 유지하도록 돕습니다.
- `LayerNormalization`: 각 벡터를 평균 0, 표준편차 1로 정규화. 학습 안정성 향상.
- `attention + ffn`: FFN의 출력에 다시 residual 연결을 적용한 것.
