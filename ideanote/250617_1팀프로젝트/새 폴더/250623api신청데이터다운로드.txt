2. 지상관측 - AWS (자동기상관측)
API명: 방재기상관측(AWS) 실시간자료 조회서비스

4. 레이더 - 강수레이더

5. 예특보 - 단기예보
API명: 단기예보 조회서비스

🎯 선택 (여유 있을 때)
7. 수치모델 - 동네예보
API명: 동네예보 조회서비스

신청 방법
기상청 API허브 회원가입: https://apihub.kma.go.kr/
각 API별 개별 신청 필요 (한 번에 전체 신청 불가)
승인 기간: 1-3일 소요
무료 이용: 일일 호출 제한 있음 (API별 다름)

공공데이터포털 vs API허브 차이점
공공데이터포털: 표준화된 API, 호출 제한 엄격
기상청 API허브: 더 세밀한 데이터, 전문적 활용
추천: 둘 다 신청해놓고 상황에 맞게 사용하는 게 좋아. API허브가 더 전문적이지만, 공공데이터포털이 안정적이거든.
20일 일정 고려하면 1-3번 API부터 먼저 신청하고, 나머지는 데이터 수집하면서 필요에 따라 추가 신청하는 게 현실적일 것 같아!

## API 키 신청 필요한 서비스

1. **공공데이터포털** (data.go.kr) - 기상청 API용
2. **통계청 SGIS** (sgis.kostat.go.kr) - 인구/행정구역 API용
3. **도로명주소 API** (juso.go.kr) - 주소 정보용

## 기술적 주의사항

- **좌표계 통일**: WGS84 (EPSG:4326) 또는 중부원점 (EPSG:5179)
- **API 호출 제한**: 기상청 일일 1000-10000회, 배치 처리 필요
- **데이터 용량**: DEM 파일 수GB, 스토리지 충분히 확보
- **전처리 시간**: 지형 데이터 처리에 1-2일 소요 예상
