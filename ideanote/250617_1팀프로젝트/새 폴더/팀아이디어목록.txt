✅ 팀 아이디어 목록 (장단점 포함 정리)
1. 상영작별 F&B 제품 수요 예측 시스템
🎬 영화관 상영작 데이터를 기반으로 팝콘, 콤보세트 등의 수요를 예측해 재고 최적화

장점: 현실적이고 적용 가능한 B2C 예측 모델 / 데이터 수집 난이도 낮음

단점: 사회적 임팩트가 다소 약하고, 인터뷰에서 어필하기 다소 약함

2. 반려동물 친환경 용품 수요 예측 시스템
🐶 친환경 사료, 배변패드 등 수요 예측으로 생산·유통 최적화

장점: MZ세대 관심도 높음 / 친환경+반려동물 = 트렌디한 키워드

단점: 실제 데이터 확보가 까다로울 수 있음 (공공데이터 부족)

3. 공공자전거·퀵보드 통합 플랫폼
🚲 여러 공유 모빌리티를 통합하여 중개 및 회원관리하는 플랫폼

장점: 실생활 편의성 / 창업 아이디어로 확장 가능

단점: 예측/AI 요소가 약함 / 데이터 분석보다는 기획 위주

4. 한국어 가짜뉴스 탐지 시스템
📰 뉴스 텍스트 분석을 통해 진짜/가짜/애매한 뉴스 3단계로 분류

장점: 사회적 관심 매우 높음 / NLP, AI 기술 어필에 강점

단점: 정답 라벨링된 데이터가 부족 / 모델 난이도 다소 높음 (BERT 등 고려해야)

5. 장마철 침수 위험 예측 시스템
🌧️ 기상, 지형, 고도 데이터를 활용해 지역별 침수 위험 실시간 예측

장점: 공공안전+실시간 예측 = 사회적 임팩트 강함 / 다양한 데이터 융합

단점: 공간 데이터 처리에 진입장벽 / QGIS, 지도API, 예보모델 등 기술학습 필요

6. 해외 인기 상품 국내 소개 쇼핑 분석
🛒 아마존, 테무 등에서 인기인 제품을 국내에 소개하고 트렌드 분석

장점: 실용적이고 흥미로운 주제 / 크롤링, 트렌드 분석 경험 가능

단점: 분석은 되지만 AI 모델/사회적 가치가 약하게 보일 수 있음

7. 숙박 검색/예약 트렌드 분석 서비스
🏡 야놀자, 아고다, 네이버 등에서 인기 숙소/지역 분석 + 최저가 탐색

장점: 사용자에게 바로 도움이 되는 분석 / 웹 시각화로 어필 용이

단점: AI나 예측 기능은 다소 약할 수 있음 / 여행 산업 외 확장성 제한

8. 스토커 100m 접근 알림 시스템
🚨 스토커 신고 시, GPS 기반으로 100m 내 접근 알림 제공

장점: 사회적 공감도 매우 높음 / 여성안전 주제로 인터뷰 호감도 상승

단점: GPS, 위치기반 기술 구현 난이도 높음 / 법적 민감도 고려 필요
