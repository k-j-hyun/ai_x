🚧 프로젝트 설명:
보험사기 탐지 웹앱을 Flask 기반으로 만들고 있습니다. 주요 구성은 다음과 같습니다:

1. 최상단 공지사항 한 줄 노출
2. 메인 화면에 '보험사기 탐지' 기능 버튼
3. 하단에는 보험사기 뉴스 영상/숏폼을 좌우로 롤링 캐러셀 형태로 보여주기
4. 다양한 게시판 (사례, 신고, 예방/대응, 유머, 자유, 문의)
5. 회원가입/로그인 기능
6. 보험사기 탐지 AI 기능 연동
7. 뉴스 크롤링 자동 업데이트

✅ 현재까지 구현한 내용:
- Flask 프로젝트 구조 세팅 완료 (`run.py`, `app/__init__.py`, `app/routes.py`)
- 메인 화면 (`/`) 연결 및 `index.html` 렌더링 확인
- static 디렉토리로 CSS, JS 분리 (`main.js`, `style.css`)
- JS로 버튼 클릭 시 alert 뜨도록 구현 완료
- 버튼 ID: `#test-button` / main.js 정상 연결 확인됨
