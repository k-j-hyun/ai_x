🚧 [진행 중인 프로젝트 설명]

Flask 기반 보험사기 탐지 웹앱을 개발 중입니다. 주요 기능은 다음과 같습니다:

1. 상단 공지사항 표시
2. 메인 화면에 보험사기 탐지 기능 입력/출력 폼
3. 하단에 뉴스 영상/숏폼 캐러셀
4. 다양한 게시판 카테고리 구성
5. 회원가입/로그인/로그아웃 기능 구현 (완료)
6. 로그인한 사용자만 글쓰기/댓글 가능하도록 제한 (완료)
7. 게시판 CRUD 기능 개발 예정
8. 보험사기 탐지 AI 기능 연동 예정
9. 뉴스 자동 크롤링 업데이트 예정

- Flask-Login 기반 회원가입/로그인/로그아웃 구현 완료
- SQLite 연동, 유저 모델 생성, 로그인 유지 세션 처리
- 로그인한 사용자만 글쓰기/댓글 가능하도록 템플릿에 조건문 추가
