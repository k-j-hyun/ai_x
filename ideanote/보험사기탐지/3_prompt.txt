나는 보험사기 탐지 웹앱 프로젝트를 진행 중이고, 현재까지 다음을 완성해놓은 상태야:

- 반응형 메인페이지 (`index.html`)
- 전체 CSS (`style.css`) 완료
- 캐러셀, 자동 배경 이미지 전환, 로그인 연동 등 기능 포함된 완성형 `main.js` 스크립트

지금부터 할 일은 다음과 같아:

1. `/detect` 라우트를 Flask에서 구현해서 텍스트 입력을 받아 머신러닝 모델로 분석하고, 결과를 다시 HTML에 전달하도록 하고 싶어.
2. 머신러닝 모델은 간단한 사기 탐지 모델을 사용하는 걸로 예시를 만들어줘 (데이터는 예시로 만들어도 괜찮아).
3. 추후 게시판 기능도 다시 추가할 예정인데, 지금은 모델 연동부터 도와줘.
