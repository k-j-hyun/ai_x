[ II ] Select문 가장 많이 쓰이는 DML(데이터 조작 언어) 질의어

SELECT [DISTINCT] {*, column [Alias], ….}
FROM 데이블명
[WHERE condition]
[ORDER BY {column, expression} [ASC|DESC]] ;

SELECT : 원하는 컬럼 선택
*	: 테이블의 모든 column 출력
alias	: 해당 column에 대한 다른 이름 부여
DISTINCT: 중복 행 제거 옵션
FROM  : 원하는 데이터가 저장된 테이블 명을 기술
WHERE : 조회되는 행을 제한하기 위한 조건 추가
condition : column, 표현식, 상수 및 비교연산자
ORDER BY:정렬을 위한 옵션 (ASC :오름차순이며 default, DECS 내림차순)




✅ 1. DDL (Data Definition Language) – 데이터 정의어
DDL은 데이터베이스의 구조(스키마) 를 정의하거나 수정할 때 사용합니다.

주요 명령어와 기능:
CREATE: 테이블, 인덱스, 뷰 등 생성
예:

sql
복사
편집
CREATE TABLE 회원 (
    회원ID NUMBER PRIMARY KEY,
    이름 VARCHAR2(50),
    가입일 DATE
);
ALTER: 기존 테이블 구조 수정 (열 추가, 수정, 삭제 등)
예:

sql
복사
편집
ALTER TABLE 회원 ADD 전화번호 VARCHAR2(20);
DROP: 객체(테이블, 뷰 등) 삭제
예:

sql
복사
편집
DROP TABLE 회원;
TRUNCATE: 테이블의 모든 데이터를 빠르게 삭제 (구조는 유지)

✅ 2. DML (Data Manipulation Language) – 데이터 조작어
DML은 테이블에 저장된 실제 데이터를 조작할 때 사용합니다.

주요 명령어와 기능:
INSERT: 데이터 삽입
예:

sql
복사
편집
INSERT INTO 회원 (회원ID, 이름, 가입일)
VALUES (1, '홍길동', SYSDATE);
UPDATE: 데이터 수정
예:

sql
복사
편집
UPDATE 회원 SET 이름 = '김철수' WHERE 회원ID = 1;
DELETE: 데이터 삭제
예:

sql
복사
편집
DELETE FROM 회원 WHERE 회원ID = 1;
SELECT: 데이터 조회
예:

sql
복사
편집
SELECT * FROM 회원 WHERE 가입일 > TO_DATE('2024-01-01', 'YYYY-MM-DD');
✅ 3. DCL (Data Control Language) – 데이터 제어어
DCL은 사용자의 권한을 제어하거나 트랜잭션(거래)의 완료/취소를 제어하는 명령어입니다.

주요 명령어와 기능:
👉 권한 제어 관련:
GRANT: 권한 부여
예:

sql
복사
편집
GRANT SELECT, INSERT ON 회원 TO 사용자A;
REVOKE: 권한 회수
예:

sql
복사
편집
REVOKE INSERT ON 회원 FROM 사용자A;
👉 트랜잭션 제어 관련 (일부는 TCL에 포함되기도 함):
COMMIT: 변경 사항 저장 (트랜잭션 완료)
예:

sql
복사
편집
COMMIT;
ROLLBACK: 변경 사항 취소 (트랜잭션 취소)
예:

sql
복사
편집
ROLLBACK;
SAVEPOINT: 롤백 시점 설정
예:

sql
복사
편집
SAVEPOINT 저장점1;
요약표:
구분	설명	주요 명령어
DDL	데이터 구조 정의	CREATE, ALTER, DROP, TRUNCATE
DML	데이터 삽입/수정/삭제/조회	INSERT, UPDATE, DELETE, SELECT
DCL	권한 및 트랜잭션 제어	GRANT, REVOKE, COMMIT, ROLLBACK, SAVEPOINT

✅ 4. TCL (Transaction Control Language) – 트랜잭션 제어어
TCL은 데이터베이스의 트랜잭션 처리를 제어하는 명령어입니다.
트랜잭션은 하나의 작업 단위를 의미하며, TCL 명령어를 통해 작업을 완료하거나 취소할 수 있습니다.

주요 명령어와 기능:
COMMIT:
변경사항을 데이터베이스에 영구 저장합니다.
예:

sql
복사
편집
COMMIT;
ROLLBACK:
트랜잭션 중 발생한 변경사항을 취소합니다.
예:

sql
복사
편집
ROLLBACK;
SAVEPOINT:
롤백을 위한 중간 저장점을 설정합니다.
예:

sql
복사
편집
SAVEPOINT 저장점1;
ROLLBACK TO SAVEPOINT:
특정 저장점까지 롤백합니다.
예:

sql
복사
편집
ROLLBACK TO 저장점1;
📌 DCL vs TCL 차이
항목	DCL	TCL
목적	사용자 권한 및 접근 제어	트랜잭션 처리 (작업의 완료/취소)
주요 명령어	GRANT, REVOKE	COMMIT, ROLLBACK, SAVEPOINT
기능	사용자에게 권한을 부여하거나 회수	데이터 변경 작업을 저장하거나 취소

요약하면, DCL 다음에 있는 건 TCL이고, 주로 COMMIT, ROLLBACK, SAVEPOINT 같은 트랜잭션 제어 관련 명령어를 포함합니다.

DML (데이터 조작어)
