TP: 진짜 Positive를 Positive로 맞힘
TN: 진짜 Negative를 Negative로 맞힘
FP: Negative인데 잘못 Positive로 예측
FN: Positive인데 잘못 Negative로 예측

        예측0    예측1
실제0  TN        FP
실제1  FN        TP

accuracy(정확도) = (TN+TP) /  (TN+FP+FN+TP)
	예: 100명 중에 90명 맞췄으면 정확도 90%
precision(정밀도) = (TP) / (FP+TP) - 예측값 기준
	"너 Positive라고 했는데, 그중 진짜 맞춘 건 몇 명이야?"
	예시:
	모델이 10명을 Positive(사기라고 예측)라고 했는데
	실제로는 7명만 진짜 사기였고, 3명은 정상인이었음
	→ precision = 7 / 10 = 70%
recall(재현율) = (TP) / (FN+TP) - 실제값 기준
	"진짜 Positive(사기인 사람) 중에서, 너 몇 명을 잡아냈냐?"
	예시:
	실제 사기꾼이 20명인데, 모델이 그 중 15명만 찾아냄
	→ recall = 15 / 20 = 75%
f1 score = recall과 precision의 조화 평균
	정밀도와 재현율의 균형
F1 = 2 * (precision * recall) / (precision + recall)
	→ 정밀도랑 재현율이 둘 다 높은 모델을 원할 때 사용!
           precision * recall
   2  *  ─────────
           precision + recall


precison(정밀도)를 높이려면 '확실한 것만' Positive로 예측
recall(재현율)을 높이려면 '조금이라도 가능성 있으면' Positive로 예측

지표	의미	강조하는 점
Accuracy	전체 중 맞춘 비율	전체 성능
Precision	예측한 Positive 중 진짜 비율	오판 줄이기
Recall	실제 Positive 중 찾은 비율	놓치지 않기
F1 Score	Precision과 Recall의 조화	균형잡힌 평가


실제 적용 예 (사기 탐지)
Precision 높이기:
→ 무고한 고객은 절대 사기라고 안 함 (신중함)

Recall 높이기:
→ 사기 가능성만 있으면 다 잡음 (놓치지 않기)
